# Credits

MeshWatch builds on these open-source projects:

- [flock-you](https://github.com/colonelpanichacks/flock-you) — Flock Safety
  camera WiFi/BLE signatures (OUIs, probe-request fingerprint, Penguin/GATT).
- [nyanBOX](https://github.com/jbohack/nyanBOX) — Flipper Zero, card-skimmer,
  drone Remote ID and Meshtastic signatures.
- [meshcore.js](https://github.com/meshcore-dev/meshcore.js) (MIT) — companion
  protocol reference and the web app's radio client (vendored in `app/vendor/`).
- Camera vendor OUIs from the public IEEE OUI registry.

Detection signatures are used for passive, defensive detection only.
